# E2E photo fixtures (feature kitchen-capture-draft)

Crops of the public-domain `infra/ai/samples/kitchen-sample.jpg` (USDA Forest Service; see
`infra/ai/samples/SOURCE.md`), generated by `apps/api/scripts/generate-heic-fixtures.sh`:

- `kitchen-1.jpg`, `kitchen-2.jpg`: 1024x768 JPEG crops (no metadata).
- `kitchen-3.heic`: 1024x768 HEIC (libheif 1.23.6 / x265) with EXIF GPS, to prove the HEIC
  path end to end (the tile must show the 512x384 server thumbnail).

Each file is under 300 kB.
